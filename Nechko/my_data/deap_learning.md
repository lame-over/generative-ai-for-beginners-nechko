# Що таке глибинне навчання?

## Визначення
Глибинне навчання (Deep Learning) — це підгалузь машинного навчання, що базується на штучних нейронних мережах з багатьма шарами ("глибоких" архітектурах). Ці моделі здатні автоматично виявляти та вивчати ієрархічні особливості даних без явного програмування.

## Ключові характеристики
- Використання багатошарових нейронних мереж (зазвичай 3+ шари)
- Автоматичне виділення ознак з необроблених даних
- Потреба у великих обсягах даних для навчання
- Використання графічних процесорів (GPU) для прискорення обчислень

## Основні архітектури
1. **Згорткові нейронні мережі (CNN)** — для обробки зображень
2. **Рекурентні нейронні мережі (RNN)** — для послідовних даних (текст, мова)
3. **Трансформери** — сучасні архітектури для NLP завдань
4. **Автокодувальники** — для навчання без учителя

## Застосування
- Розпізнавання зображень та об'єктів
- Обробка природної мови (NLP)
- Генеративні моделі (GAN, дифузійні моделі)
- Автономні транспортні засоби
- Медична діагностика
