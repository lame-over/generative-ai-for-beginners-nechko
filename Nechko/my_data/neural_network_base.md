НАЗВА: Нейронні мережі - основи архітектури

ОСНОВНІ КОМПОНЕНТИ НЕЙРОННИХ МЕРЕЖ:

1. НЕЙРОНИ (ВУЗЛИ)
   - Базові обчислювальні одиниці
   - Приймають вхідні дані, обробляють їх і передають далі
   - Мають вагові коефіцієнти, які налаштовуються під час навчання

2. ШАРИ МЕРЕЖІ
   - Вхідний шар: отримує необроблені дані
   - Приховані шари (1 або більше): виконують основні обчислення
   - Вихідний шар: видає кінцевий результат

3. ФУНКЦІЇ АКТИВАЦІЇ
   - ReLU (Rectified Linear Unit): найпопулярніша, f(x)=max(0,x)
   - Сигмоїда: f(x)=1/(1+e^-x), діапазон (0,1)
   - Tanh: гіперболічний тангенс, діапазон (-1,1)
   - Softmax: для багатокласової класифікації

4. ПРОЦЕС НАВЧАННЯ
   - Пряме поширення (forward propagation)
   - Обчислення функції втрат (loss function)
   - Зворотне поширення помилки (backpropagation)
   - Оптимізація (градієнтний спуск)

5. ВИДИ НАВЧАННЯ
   - З учителем: навчання на розмічених даних
   - Без учителя: виявлення паттернів у нерозмічених даних
   - З підкріпленням: навчання через взаємодію з середовищем
