# Курси з глибинного навчання

## 1. Основи глибинного навчання

### Короткий опис
Вступний курс, що охоплює фундаментальні концепції нейронних мереж та глибинного навчання. Практичний курс з використанням Python та PyTorch/TensorFlow.

### Перелік тем/модулів
1. Введення в машинне навчання та нейронні мережі
2. Лінійні моделі та градієнтний спуск
3. Багатошарові перцептрони та функції активації
4. Реалізація нейронних мереж з нуля
5. Введення в PyTorch/TensorFlow
6. Налаштування гіперпараметрів
7. Боротьба з перенавчанням (регуляризація, dropout)
8. Практичний проект: класифікація зображень

### Вимоги до попередніх знань
- Базове знання Python
- Основи лінійної алгебри (вектори, матриці)
- Основи математичного аналізу (похідні)
- Основи ймовірності та статистики

### Практичні завдання
1. Реалізація градієнтного спуску для лінійної регресії
2. Створення нейронної мережі з нуля на NumPy
3. Класифікація рукописних цифр (MNIST) за допомогою PyTorch
4. Аналіз впливу різних функцій активації
5. Реалізація dropout та L2-регуляризації

### Очікувані результати навчання
- Розуміння принципів роботи нейронних мереж
- Вміння реалізовувати базові моделі на PyTorch/TensorFlow
- Навички налаштування гіперпараметрів
- Досвід роботи з реальними датасетами

---

## 2. Згорткові нейронні мережі (CNN)

### Короткий опис
Поглиблений курс, присвячений архітектурам CNN та їх застосуванню в комп'ютерному зорі. Курс включає детальний аналіз сучасних архітектур.

### Перелік тем/модулів
1. Основи обробки зображень для CNN
2. Принципи згортки та пулінгу
3. Архітектури LeNet, AlexNet, VGG
4. Residual Networks (ResNet) та skip connections
5. Transfer learning та fine-tuning
6. Детекція об'єктів (R-CNN, YOLO, SSD)
7. Сегментація зображень (U-Net, Mask R-CNN)
8. Генеративні моделі для зображень (VAE, GAN)

### Вимоги до попередніх знань
- Завершений курс "Основи глибинного навчання"
- Розуміння нейронних мереж
- Базові знання лінійної алгебри
- Досвід роботи з PyTorch/TensorFlow

### Практичні завдання
1. Реалізація згорткового шару з нуля
2. Тренування CNN на CIFAR-10 датасеті
3. Transfer learning з використанням ResNet
4. Реалізація простої версії YOLO
5. Створення U-Net для сегментації медичних зображень
6. Тренування GAN для генерації зображень

### Очікувані результати навчання
- Глибоке розуміння архітектур CNN
- Вміння застосовувати transfer learning
- Навички вирішення реальних задач комп'ютерного зору
- Досвід роботи зі складними архітектурами

## 3. Обробка природної мови з використанням трансформерів

### Короткий опис
Сучасний курс, що охоплює передові техніки NLP з акцентом на трансформерах. Курс включає роботу з BERT, GPT та іншими великими мовними моделями.

### Перелік тем/модулів
1. Введення в NLP та векторизацію тексту
2. Word embeddings (Word2Vec, GloVe, FastText)
3. Рекурентні мережі (RNN, LSTM, GRU) для NLP
4. Принципи роботи трансформерів
5. Архітектура BERT та його варіанти
6. GPT та авторегресивні моделі
7. Fine-tuning великих мовних моделей
8. Мультимодальні моделі (CLIP, DALL-E)
9. Оптимізація великих моделей (дистиляція, квантування)

### Вимоги до попередніх знань
- Продвинуте знання Python
- Досвід роботи з нейронними мережами
- Базові знання теорії ймовірностей
- Знайомство з PyTorch/TensorFlow

### Практичні завдання
1. Створення word embeddings з нуля
2. Класифікація текстів за допомогою LSTM
3. Fine-tuning BERT для задачі NER
4. Створення чат-бота на базі GPT-2
5. Реалізація мультимодальної класифікації
6. Дистиляція великої моделі у меншу

### Очікувані результати навчання
- Розуміння сучасних архітектур для NLP
- Навички роботи з великими мовними моделями
- Вміння адаптувати попередньо навчені моделі
- Досвід вирішення практичних NLP задач

## 4. Генеративні моделі та творчий AI

### Короткий опис
Просунутий курс, що вивчає генеративні моделі для створення контенту. Курс охоплює VAE, GAN, дифузійні моделі та їх застосування.

### Перелік тем/модулів
1. Варіаційні автокодувальники (VAE)
2. Generative Adversarial Networks (GAN)
3. Умовні GAN та контроль генерації
4. StyleGAN та генерація високоякісних зображень
5. Дифузійні моделі (DDPM, Stable Diffusion)
6. Генеративні моделі для тексту
7. Мультимодальна генерація
8. Етика генеративних моделей
9. Оцінка якості генеративних моделей

### Вимоги до попередніх знань
- Глибоке розуміння нейронних мереж
- Досвід роботи з CNN
- Знайомство з теорією ймовірностей
- Продвинуте знання PyTorch

### Практичні завдання
1. Реалізація VAE для генерації цифр
2. Тренування DCGAN на датасеті облич
3. Створення умовного GAN для контролю генерації
4. Fine-tuning дифузійної моделі
5. Генерація текстів за допомогою GPT
6. Створення моделі для text-to-image генерації

### Очікувані результати навчання
- Розуміння принципів генеративних моделей
- Навички тренування складних GAN архітектур
- Вміння створювати креативні AI системи
- Досвід роботи з дифузійними моделями

## 5. Розгортання та оптимізація моделей глибинного навчання

### Короткий опис
Практичний курс, що навчає впроваджувати та оптимізувати ML-моделі для реальних застосунків. Курс охоплює MLOps, оптимізацію та масштабування.

### Перелік тем/модулів
1. MLOps: принципи та інструменти
2. Контейнеризація ML-додатків (Docker)
3. Відстеження експериментів (MLflow, Weights & Biases)
4. Оптимізація моделей (прунінг, квантування, дистиляція)
5. Розгортання моделей (TorchServe, TensorFlow Serving)
6. Масштабування тренувань (distributed training)
7. Моніторинг та підтримка продакшен моделей
8. AutoML та автоматизація процесів
9. Етика та відповідальне розгортання AI

### Вимоги до попередніх знань
- Досвід тренування глибинних моделей
- Базові знання Linux та командного рядка
- Досвід роботи з Git
- Розуміння хмарних сервісів

### Практичні завдання
1. Створення Docker-образу для ML-моделі
2. Налаштування MLflow для відстеження експериментів
3. Квантування моделі для мобільних пристроїв
4. Розгортання моделі через REST API
5. Налаштування distributed training
6. Створення пайплайну CI/CD для ML
7. Моніторинг дрейфу даних у продакшені

### Очікувані результати навчання
- Навички розгортання ML-моделей у продакшен
- Вміння оптимізовувати моделі для різних платформ
- Досвід роботи з MLOps інструментами
- Розуміння повного життєвого циклу ML-проекту
